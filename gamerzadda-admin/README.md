# GamerzAdda Admin — Clean Starter

1. Copy `.env.local.example` to `.env.local`.
2. Put your Supabase URL + anon/publishable key in `.env.local`.
3. Keep the backend URL in `NEXT_PUBLIC_API_URL`.
4. Run `npm install` then `npm run dev`.
5. Open `http://localhost:3000/admin/login`.

Included:
- Admin login
- Admin dashboard
- Tournament list/manage
- Create tournament + saved prize distribution
- Tournament management
- Results page
- Supabase client
- API rewrite to backend

Do NOT put `SUPABASE_SERVICE_ROLE_KEY` in this frontend project.
